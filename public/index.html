Endpoints

JSON over HTTPS. The live engine (POST /api/turn, /api/review, /api/cue) powers the screen above.

  • GET/api/c5/demo→The held-out safety call, pre-played through the live engine: every tag, the red banner at 05:12, the cues and the score.
  • GET/api/c5/agreement→Score vs supervisors with CIs, the per-call table, and the safety-flag results.
  • GET/api/c5/calls[/:callId]→The 27 supervisor-labelled demo calls, scored with the live screen's arithmetic.
  • GET/api/c5/survivors[/:id]→One row per participant, with status from their worst call.

Reproduce

Batch scripts share the live model quota. Do not run them during a demo.

github.com/zaycruz/coach-copilot →
  1. npm install

    Then npx wrangler deploy serves the Worker at coach.raava.dev.

  2. uv run --with pandas python -I scripts/evaluate.py <data_dir> validation 0 @cf/cloudflare/clef 2 --flags-only

    Scores the safety flags on the held-out validation calls.

  3. uv run --with pandas python -I scripts/annomi_bench.py <data_dir>

    The real expert benchmark (AnnoMI), with the shipped payload unchanged.
